Score = exact match with the correct concept, on the Windows laptop. Sorted by each model's best score without the oracle hint. No tools: the model answers from memory. Search: a keyword search over all 17,388 concepts gives the model 100 candidates to choose from. Search + numeric: the search is limited to numeric concept types, a fixed list that does not look at the test items. Oracle diagnostic: the search is limited to the item's given type, which is the correct concept's type for every item. A real system would not have this, so that column shows a best case, not a deployable result. For reference, the FinTagging paper reports GPT-4o 18.3% and Llama-3.1-8B 9.1% on its full test set with its own retriever.

Each question asks for one number, for example the net present value of a project. Correct = within 1% of the answer. No tools: the model works it out in text. Formula lookup + calculator: a keyword search finds a formula among 50 named formulas (the right one for 844 of 1,000 questions), the model writes one arithmetic expression, and a calculator evaluates it. Windows laptop. These runs were not profiled, so no latency or memory is shown.
